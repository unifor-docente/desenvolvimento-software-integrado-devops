# Prática — revisão de código com IA usando CodeRabbit

**Encontro 2 · GitHub Flow, pull requests e qualidade · 45–60 minutos.**

A aplicação desta prática está em um repositório próprio:

- [API, testes e roteiro completo](https://github.com/unifor-docente/devops-coderabbit-demo)
- [PR nº 1 — demonstração de desconto percentual](https://github.com/unifor-docente/devops-coderabbit-demo/pull/1)

## Condução da aula

1. Clone o repositório da API e execute `npm test` e `npm start` dentro de `app`.
2. Conecte o CodeRabbit ao repositório `unifor-docente/devops-coderabbit-demo`.
3. Selecione o PR nº 1 na tela de demonstração do CodeRabbit e inicie a revisão.
4. Analise os comentários da IA e reproduza os defeitos de desconto.
5. Adicione os testes de regressão, corrija e envie um novo commit para o mesmo PR.
6. Compare os testes e a nova revisão antes da decisão humana de merge.

O README da aplicação contém comandos, critérios de aceite, solução guiada e evidências esperadas. O PR inicial tem defeitos intencionais e deve permanecer sem merge até a correção.

> Toda saída de IA é hipótese até ser validada por teste, execução ou revisão humana.

Este exemplo apoia a aula; a escolha da aplicação do projeto integrador continua livre.
